# 🪪 Passport OCR AI

Веб-приложение на базе нейросетей для автоматического распознавания и извлечения текстовых данных из фотографий и сканов паспортов. 

Проект построен с использованием **Streamlit** для веб-интерфейса и предобученных глубоких нейросетей (ResNet + LSTM) движка **EasyOCR** для оптического распознавания текста (OCR).

---

## ✨ Основные возможности
* 🔎 **Автоматическое извлечение данных:** распознает серию, номер, дату выдачи и код подразделения с помощью регулярных выражений (RegEx).
* 🇷🇺 **Мультиязычность:** движок OCR настроен на одновременное чтение кириллицы (русский язык) и латиницы (английский).
* 📷 **Предобработка изображений:** встроенные алгоритмы OpenCV автоматически масштабируют и фильтруют загруженные фото для повышения точности распознавания.
* 💻 **Удобный Web UI:** интуитивный интерфейс, адаптированный под мобильные устройства и десктопы.

---

## 🛠 Стек технологий
* **Python 3.10+** — основной язык разработки
* **Streamlit** — фреймворк для создания веб-интерфейса
* **EasyOCR** — библиотека глубокого обучения для распознавания текста (на базе PyTorch)
* **OpenCV & Pillow** — обработка и оптимизация изображений

## 🚀 Быстрый запуск на локальном компьютере

Если вы хотите запустить проект у себя локально, выполните следующие шаги:

### 1. Клонируйте репозиторий
```bash
git clone https://github.com
cd ИМЯ_РЕПОЗИТОРИЯ
```

### 2. Установите зависимости
Рекомендуется использовать виртуальное окружение (`venv`):
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или
venv\Scripts\activate     # Для Windows

pip install -r requirements.txt
```
*(При первом запуске EasyOCR автоматически скачает веса нейросетевых моделей для русского и английского языков в фоновом режиме, это займет около 100-150 МБ).*

### 3. Запустите приложение
```bash
streamlit run app.py
```
После этого интерфейс автоматически откроется в вашем браузере по адресу `http://localhost:8501`.

## 🌐 Развертывание (Деплой)
Проект полностью готов к бесплатному деплою на платформе **Streamlit Community Cloud**. 
1. Создайте аккаунт на [share.streamlit.io](https://streamlit.io).
2. Подключите ваш GitHub.
3. Выберите данный репозиторий и ветку `main`, укажите главный файл `app.py` и нажмите **Deploy**.

## 📝 Важное примечание (Disclaimer)
Данная нейромодель создана в демонстрационных целях. Обработка изображений происходит локально в оперативной памяти сервера (Streamlit Cloud) и **не сохраняется** в сторонних базах данных, что обеспечивает базовую конфиденциальность при тестировании.
